Resolving the desktop.ini Error When Using GitHub and Google Drive Together

12 January 2024 · writing · history

Here is a fix for the fatal: git show-ref: bad ref refs/tags/desktop.ini error that shows up when you try to back up files with both GitHub Desktop and Google Drive in the same directory.

All we need to do is delete the desktop.ini files that Google Drive creates. Rather than delete them one by one, I wrote a small Python script that finds and removes files with a given name in a chosen directory. The code is on GitHub.

Running it

  • Make sure Python is installed.
  • Open a terminal and go to the project directory.
  • Run the program.

You will be asked for the directory to scan and the file name to delete:

> Which directory do you want to scan?  C:\Users\efe\Desktop\Lecture Notes\...
> What is the file name?  desktop.ini

After scanning, the program reports how many files it found and asks for confirmation before deleting them. Once they are gone, GitHub works normally again.

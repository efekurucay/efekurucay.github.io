tiro
Closed-circuit AI for criminal defence lawyers. A desktop application: neither the case file nor the draft defence ever leaves the machine. It runs a local model we trained ourselves on Turkish criminal case files and legal language, with no internet connection at all. Seven modules: a source-anchored defence editor exporting UYAP-ready UDF, a document flow that opens UDF, PDF and scanned material on one surface, an event timeline, a person–evidence–place relationship map, per-person case summaries and offline search across Turkish penal and procedural codes. Every generated sentence shows which page of which document it came from. Named after Cicero's assistant Tiro: it records, summarises and organises — the lawyer forms the judgement.

Selected work

plexcode
Open source TUI that brings Perplexity Pro to the terminal through an existing session — no API key. Playwright, Node. Reads local files in agentic mode. TypeScript.
RLeon
Native macOS AI assistant running fully on-device through Ollama: tool calling, OCR and speech-to-text. Hold fn and it sends a screenshot plus your speech to a local model; tap and hold and it types transcribed speech at the cursor. Swift.
turkish-disinfo-rationale
LoRA generating fact-check rationales for Turkish claims. Qwen3.6-35B-A3B, Tinker SFT.
tam-cli
Terminal alias manager for macOS. Manage ~/.zshrc through a SwiftUI interface. Swift.
keyseed
Deterministic secret generation instead of secret storage. Same input plus same master key yields the same ciphertext. PBKDF2 (SHA-256, 210k iterations) for key derivation, AES-256-GCM-SIV with fixed nonce and salt, key material zeroized after use. Rust binary distributed through npm.
callscoot
Turns a Linux laptop into a call runtime for an Android phone — the computer acts as the phone's Bluetooth headset. Self-hosted call infrastructure over ADB and Bluetooth, or a SIP server; LLM, TTS and STT in the processing layer with ElevenLabs voice agent integration. Python.
Fibiyo — AI-first e-commerce platform
AI product image generation for sellers, a short-video section, AI description generator and review summariser. Customer, seller and admin roles on a layered architecture. Java Spring Boot, Angular, MySQL.
Anka — AI fairytale generator

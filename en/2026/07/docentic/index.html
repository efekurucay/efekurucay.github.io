docentic

July 2026 · project · JavaScript · source · history

An embeddable, self-hosted agentic assistant for static sites. A visitor asks a question; docentic walks the site's own content with tools — search, read pages — and answers, streamed, in the visitor's language.

Think Web3Forms, but instead of a form endpoint you get a small AI agent that knows your site. You run it on your own server, with your own model key, and drop one <script> tag into any static site.

How it works

  • No framework, no build for the client — one widget.js
  • One SQLite file holds the crawled content (FTS5), sessions and messages
  • An agentic loop over a read-only toolset; the model decides what to read
  • OpenRouter for the model layer (any model via one key), with a fallback
  • Isolated sessions — one visitor never sees another's conversation

The assistant on this site is the same idea: a reader can ask the site instead of asking me.

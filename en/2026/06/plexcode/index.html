plexcode

13 June 2026 · project · TypeScript · source · history

A local API proxy that runs CLI coding assistants through the Perplexity Pro or Max web session you already have open.

Why

I had a Perplexity subscription. The coding assistant in my terminal wanted a separate API key and a separate bill. Paying twice made no sense.

What it does

It opens a local server that presents itself as a familiar API. Requests go through the browser session and come back in the same shape. On the assistant's side, the only thing that changes is the base URL.

Notes

Tools like this live and die by changes on the other side; I make no claim that it is permanent. I wrote it for myself and left it open.

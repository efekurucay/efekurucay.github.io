AnyDisplay

GitHub

25 October 2026 · project · Kotlin, Swift, Rust · source · history

AnyDisplay turns the Android phone or tablet in your drawer into a second screen for your computer. It connects over a USB cable or the same Wi-Fi; your desktop extends onto the tablet and you drag windows there. If the tablet has a stylus, it becomes a drawing tablet with pressure and tilt.

Apps that do this exist, but they are closed source, most cost money and most support only one desktop OS. AnyDisplay is MIT-licensed, one Android app works with both Mac and Windows, and the protocol between them is open, so anyone can write their own client or host.

What it does

  • A real extended display: on a Mac it creates a virtual monitor at the device’s resolution, HiDPI, up to 120 Hz; on Windows through the Virtual Display Driver
  • Hardware video: H.264 and HEVC on both ends, low-latency settings, at most 3 frames in flight
  • Pen: pressure, tilt, hover, eraser and barrel button, with palm rejection
  • Touch: direct multi-touch, trackpad mode, two-finger scrolling
  • Keyboard, audio, clipboard: typing in any language, computer audio on the device, clipboard both ways
  • Security: P-256 key exchange, the same 6-digit code on both screens when pairing, AES-256-GCM on every Wi-Fi frame

How fast

Measured with a Huawei P30 Pro and a MacBook Pro: 60 fps over USB with no dropped frames, 5–7 ms decode and about 3 ms round trip. Over encrypted Wi-Fi it still runs at 60 fps with a 7–20 ms round trip.

How to use it

  1. From the latest release, download the APK to the device and the macOS or Windows package to the computer.
  2. Open AnyDisplay on the device. For USB, turn on USB debugging in the developer options.
  3. Start AnyDisplay on the computer and connect. On the first Wi-Fi connection, confirm the code shown on both screens.

Questions

Can an Android tablet be a second monitor for a Mac? Yes. Apple’s Sidecar works only with an iPad; AnyDisplay does the same with Android devices, using a real virtual monitor on macOS 14 and later.

Is it free? Yes, MIT-licensed open source. No ads, no account, no subscription.

Does it work wirelessly? Yes. The device announces itself on the network with Bonjour/mDNS; the first connection pairs with a 6-digit code and later ones connect on their own.

What about Windows? The Windows host builds and passes its tests on Windows, but it has not been tried with a real device yet; reports from anyone who tries it help a lot.

NFCraft reads, writes, automates and emulates NFC tags from one clean app. Hold a tag to the back of your phone and it identifies the chip, shows the serial, verifies whether the tag is genuine, and decodes its content. You can write your own data back, carry automation on a tag, or turn the phone itself into a tag.

The NFC apps people reach for are dated and cluttered. NFCraft is a modern, ground-up rewrite built on open NFC Forum standards and public chip datasheets, in Jetpack Compose on Android and SwiftUI on iOS. No ads, no analytics, no trackers — the only permission the core needs is NFC.

What it does

  • Read & identify: NTAG, MIFARE Ultralight, Classic/Plus, DESFire, ICODE and FeliCa — chip type, UID, memory and decoded NDEF
  • Genuine-tag check: verifies the manufacturer originality signature (secp128r1 ECDSA, pure Kotlin) so you know an NXP tag is real, not a clone
  • Write: eleven NDEF record types (URL, text, Wi-Fi, contact, email, SMS, geo, app and more), with a live size readout and optional lock
  • Automate: 220 tasks across ten categories; scan a tag and run them, with if/else conditions. Root and destructive tasks are off by default behind a confirmation
  • Emulate: turn the phone into an NFC Forum Type 4 tag over Host Card Emulation
  • Tools: full memory dump, password protection, make-read-only, profiles (JSON/CSV), a raw APDU console, a home-screen widget and shortcuts

How to use it

  1. Download the APK with the button above and install it (allow installing from your browser or file manager).
  2. Open NFCraft and hold a tag to the back of the phone to read it.
  3. To write, build a record on the Write tab and tap the tag; to automate, pick a task and write it, then scan to run.

Questions

Is NFCraft free and open source? Yes. It is MIT-licensed, with no ads, no analytics and no account. The NFC core asks only for the NFC permission.

Which NFC tags does it support? It reads NTAG, MIFARE Ultralight, Classic and Plus, DESFire, ICODE and FeliCa, and writes NDEF to Type 2 tags (NTAG / Ultralight) — including factory-blank ones, which it formats first.

Can it tell if an NFC tag is genuine? Yes. For NXP tags it reads the originality signature and verifies it (secp128r1 ECDSA) against the embedded manufacturer key, so a cloned tag fails the check.

Does it work on iPhone? There is a native iOS app for NDEF read and write. iOS only exposes a small slice of NFC to third-party apps, and NFC there needs a paid Apple Developer account — so the full toolkit lives on Android.

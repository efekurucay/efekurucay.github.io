tam-cli

25 March 2026 · project · Swift · source · history

A native terminal alias manager for macOS. It lets you see and edit the aliases in your ~/.zshrc from a SwiftUI interface.

Why

I had no idea what half of my accumulated aliases did. Open the file, search, break something by accident, then fight the shell that will not start — the same loop every time.

What it does

  • List, search, edit and delete aliases
  • Back up the file before writing to it
  • Check syntax so it never writes a broken line
  • Native SwiftUI — not Electron

Currently my most starred project, which suggests the annoyance was not mine alone.

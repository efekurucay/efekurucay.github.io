keyseed

March 2026 · project · Rust · source · history

A local-first CLI that reproduces secrets instead of storing them. Give it a label and a master key; it returns a payload. Same label plus same master key always returns the same output.

Why

A password manager stores your secrets somewhere. keyseed keeps nothing: the secret is derived on demand from something you type and something you remember. Nothing to leak, nothing to sync.

How it works

  • Key derivation with PBKDF2 (SHA-256, 210k iterations)
  • AES-256-GCM-SIV with fixed nonce and salt for deterministic output
  • Versioned format: hashit:v2:…
  • Key material zeroized after use
  • Rust binary, distributed through npm (npx keyseed)
keyseed encrypt "efe.facebook" -k "master-key"
keyseed decrypt "hashit:v2:..."  -k "master-key"

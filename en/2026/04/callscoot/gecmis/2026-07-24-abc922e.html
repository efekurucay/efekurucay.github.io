callscoot

April 2026 · project · Python · source · history

Turns an always-on Linux box into a call console for an Android phone. The laptop behaves like the phone's Bluetooth headset: call audio comes over Bluetooth, the laptop mic goes back to the phone, the speakers play the caller.

Why

A self-hosted call runtime. Outside apps hit a local HTTP API, so there is no business logic on this side — the phone (via ADB and Bluetooth) or a SIP server is just the call source. What sits in the middle is yours to shape.

What is in it

  • Bluetooth HFP/HSP audio bridge, echo cancellation on by default
  • ADB helpers to dial, answer and hang up Android calls
  • Optional SIP mode: register to a server and place calls directly
  • Call policies: auto-answer / auto-reject
  • Real-time voice-agent mode inside the call (tried OpenAI models, settled on ElevenLabs for streaming)
  • Local HTTP API so another app can use it as a call runtime
  • Runs as a headless user service

Linux-first: Debian 13, BlueZ 5.82, PipeWire 1.4.x. Next: fully local model and agent orchestration, and exposing the phone's connection as a SIP server to peel off the ADB/Bluetooth layer.

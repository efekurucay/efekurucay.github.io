gitdex

April 2026 · project · JavaScript · source · history

Makes a whole repository understandable for an LLM. gitdex scans a local codebase and converts it into clean text bundles with less noise and a clearer structure.

Why

Feeding a repo to a model file by file loses the shape of it. gitdex packs the whole thing so the model sees the structure, not just fragments — and spends fewer tokens doing it.

What it does

  • Root files become separate .txt files; each top-level directory merges into one
  • Every block starts with its relative path
  • Skips binaries, .git, node_modules, lockfiles, minified bundles and build dirs
  • Compresses whitespace, license headers and comments to cut tokens
  • Splits oversized output at safe boundaries, never mid-function
  • Writes a 00-index.txt map so the model can navigate

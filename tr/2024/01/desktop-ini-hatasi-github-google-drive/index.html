GitHub ve Google Drive'ı birlikte kullanınca çıkan desktop.ini hatası

12 Ocak 2024 · yazı · geçmiş

GitHub Desktop ile Google Drive'ı aynı klasörde kullanıp yedek almaya çalışınca çıkan fatal: git show-ref: bad ref refs/tags/desktop.ini hatasının çözümü.

Tek yapmamız gereken, Google Drive'ın oluşturduğu desktop.ini dosyalarını silmek. Tek tek silmek yerine, seçilen klasörde belirtilen isimdeki dosyaları bulup silen küçük bir Python kodu yazdım. Kod GitHub'da.

Çalıştırma

  • Bilgisayarında Python kurulu olsun.
  • Terminali aç ve proje klasörüne geç.
  • Programı çalıştır.

Taranacak klasör ve silinecek dosya adı sorulacak:

> Hangi klasörü taramak istiyorsun?  C:\Users\efe\Desktop\Lecture Notes\...
> Dosya adı nedir?  desktop.ini

Tarama sonrası program kaç dosya bulduğunu söyler ve silmeden önce onay ister. Dosyalar silinince GitHub yeniden normal çalışır.
